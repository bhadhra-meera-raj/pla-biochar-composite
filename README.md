# PLA-Biochar Composite and Corrosion Behaviour in Alkaline Medium

## Overview

This project investigated the preparation of PLA-biochar composite materials and evaluated their corrosion behaviour in an alkaline medium.

## Objectives

- Prepare PLA-biochar composite materials
- Study the effect of biochar incorporation on the composite
- Evaluate corrosion behaviour in an alkaline environment
- Characterize and analyze the resulting material properties

## Methodology

The PLA-biochar composites were prepared and evaluated using appropriate material processing and characterization techniques. Corrosion behaviour was investigated by exposing the composites to an alkaline medium and analyzing their performance.

## Skills & Techniques

- Polymer Processing
- Composite Materials
- Material Characterization
- Corrosion Testing
- Experimental Analysis
- Data Analysis

## Result

- Developed a PLA-biochar composite with 5 wt% coconut shell-derived biochar via solution casting using chloroform as solvent.
- Analyzed corrosion behaviour in alkaline medium over 7 days, benchmarking against pure PLA and reducing weight loss from
20% to 17%.
- Documented experimental procedures, findings, and technical conclusions through project reports and presentations
